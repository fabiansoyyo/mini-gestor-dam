# MiniGestorDAM

MiniGestorDAM es una aplicación Java sencilla que simula un sistema de gestión de incidencias.

## Funcionalidades

- Registrar una incidencia mediante un título y una descripción.
- Asignar una prioridad en función del nivel de urgencia introducido por el usuario:
  - BAJA
  - MEDIA
  - ALTA
- Mostrar un resumen de la incidencia registrada.

## Objetivo de la práctica

El objetivo principal del proyecto es aplicar un flujo de trabajo colaborativo utilizando Git y GitHub, incluyendo:

- Creación de ramas.
- Commits independientes.
- Pull Requests.
- Revisión de código.
- Corrección tras feedback.
- Merge de cambios en la rama principal.
